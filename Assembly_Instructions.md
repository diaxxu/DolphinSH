# VTOL Aircraft Assembly Instructions

## 1. Wing Assembly
1. Assemble the wing structure according to the wing layout drawing.
2. Insert and secure the carbon fiber reinforcement rods inside the wing.
3. Install the wing servo in its designated servo bay.
4. Secure the servo and connect the control linkage to the control surface.
5. Verify smooth movement and ensure there is no binding.

## 2. Fuselage Assembly
6. Assemble the fuselage structure.
7. Install the rear fuselage servo in its mounting location.
8. Secure the servo and connect the linkage.
9. Verify full and smooth control surface deflection.
10. Mount the flight controller inside the fuselage using M3 screws.
11. Use vibration isolation if required.

## 3. Structural Integration
12. Slide the wing into the fuselage and secure it according to the design.
13. Insert the carbon fiber square tubes (booms) through the wing structure.
14. Ensure correct alignment and equal extension on both sides.
15. Install the four motor pods, one at each end of the booms.
16. Secure the motor pods firmly.

## 4. Motor Installation
17. Mount the four VTOL motors into the motor pods.
18. Install the cruise motor in the nose.
19. Tighten all mounting screws and apply threadlocker where appropriate.

## 5. Wiring and Electronics
20. Route all motor and servo wires through their designated channels and openings.
21. Extend motor and servo wires as required.
22. Solder all connections to the flight controller according to the official wiring diagram.
23. If using a different flight controller, refer to its specific pinout documentation.
24. Install the FPV camera in the nose and secure it.
25. Install all remaining avionics inside the fuselage (ESCs, GPS, receiver, power distribution, etc.).
26. Secure all components to prevent vibration or movement.

## 6. Final Checks
27. Verify the center of gravity (CG).
28. The CG must be located at 25% of the wing chord measured from the leading edge.
29. Perform control surface direction checks.
30. Verify motor rotation direction.
31. Confirm firmware configuration and failsafe operation before flight.
